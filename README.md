# 8B4T - Футуристический Minecraft Сервер

Современный веб-сайт для Minecraft сервера с футуристическим дизайном в стиле киберпанк.

## 🌟 Особенности

- **Футуристический дизайн** - Современный UI в стиле киберпанк
- **Система регистрации и авторизации** - Полноценная система пользователей
- **Защита от атак** - ограничение запросов, валидация данных
- **Адаптивный дизайн** - Работает на всех устройствах
- **Интерактивные элементы** - Анимации, уведомления, копирование в буфер
- **Статус сервера** - Отображение онлайн игроков и состояния сервера

## 🛡️ Безопасность


- **Ограничение запросов** - Защита от DDoS и брутфорс атак
- **Валидация данных** - Проверка всех пользовательских данных
- **Хеширование паролей** - Безопасное хранение паролей
- **Блокировка аккаунтов** - Автоматическая блокировка при неудачных попытках входа
- **Логирование** - Отслеживание попыток входа

## 🚀 Установка

### Требования

- Python 3.8+
- pip

### Шаги установки

1. **Клонируйте репозиторий:**
```bash
git clone <repository-url>
cd minecraft-server-website
```

2. **Создайте виртуальное окружение:**
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

3. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

4. **Запустите приложение:**
```bash
python app.py
```

5. **Откройте браузер:**
```
http://localhost:55555
```

## 🔧 API

### Эндпоинты:

- `GET /` - Главная страница
- `GET /register` - Страница регистрации
- `POST /register` - Регистрация пользователя
- `GET /login` - Страница входа
- `POST /login` - Авторизация
- `GET /dashboard` - Панель управления
- `GET /server-info` - Информация о сервере
- `GET /api/server-status` - API статуса сервера
- `POST /logout` - Выход из системы
